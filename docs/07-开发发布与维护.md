# 开发发布与维护

Node25、TypeScript、React18、Ajv和esbuild使用package-lock固定，SDK与共享色板保存公开来源及摘要。专业领域不依赖Electron、Cordis内部或Rust私有代码；无需FFI和原生动态库。

```bash
npm ci
npm run build
npm run check
npm run test:unit
npm run package
node scripts/verify-docs.mjs
python3 scripts/accept-installed.py
```

acceptance-lock固定正式宿主源码、签名归档和插件目录摘要，machine／cross／ui分别取证；macOS图形测试需实际会话。安装副本使用隔离目录，不替换其他会话维护的共享应用。原请求和管理绑定只留output，不发布私密上下文。

发布顺序：完整源码与正式安装验收→提交最终源码→固定tgz及目录双摘要→不可变v0.1.0 Tag和Release→公开重新下载逐文件核验→安装回读→插件中心→中英指南、博客、真实工作面→生产浏览器与响应核验。公开同版本附件不覆盖，未知先读原发布与安装状态。

领域维护同步02／03、可执行Schema、CAPABILITIES、包内Skill、04正反例与验收；进度唯一Owner为08。宿主不足时先补通用Owner合同，不绕过来源、事务或正文采纳。参考项目及许可只读记录归research，GPL和未授权内容不进入运行包。
