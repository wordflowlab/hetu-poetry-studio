# 用户用例与验收矩阵

| 用例 | 正向 | 反向 |
| --- | --- | --- |
| 01 自由诗 | 保留分节和行序，不要求填写格律 | 未标注音韵保持未知 |
| 02 声明谱式 | 按明确出处和P/Z/*模式核对长度及逐字位置 | 不把现代调值当传统平仄 |
| 03 多音字与异体字 | 相同字不同位置可有不同声明 | 读音位置越界和字面不匹配拒绝 |
| 04 用典 | 固定原文区间与说明 | UTF-8错位、错引文、跨作品来源拒绝 |
| 05 逐句备选 | 固定旧句，新句清空过期音韵 | 旧摘要和悬空引用拒绝 |
| 06 组诗 | 多篇分节与独立顺序，导出完整阅读本 | 不能遗漏未选诗篇后宣称整集 |
| 07 格式导入 | 固定原件按换行和空行预览再追加 | 原件不可改写，空白输入拒绝 |
| 08 精确作品 | 小说、剧本、视频各自固定来源 | 错WorkRef、撤权和错误来源拒绝 |
| 09 恢复 | 同键同参、写后丢回执、原操作回读 | 同键异参、旧基线不覆盖 |
| 10 热插拔 | 同一MCP连接发现Skill及启停卸载重装 | 旧活动包及能力绑定拒绝 |
| 11 交付 | 重组全部字节、核对内容和损失 | 只下载首块不算完整 |
| 12 实际审核 | 五页浅暗1360／760、键盘、取消、CAS、关闭恢复 | 不以可渲染替代业务 |
| 13 专业组合 | 三包通过同作品固定依据接续并形成宿主下一稿候选 | 不合并权限、不修改正式正文 |

单元覆盖领域不变量、反例和格式边界；机器逐项覆盖可执行动作与Skill；当前Codex会话真实发现安装包、读取来源、保存并回读原操作。真实作品品质与作者判断单列，合成案例不冒充真人研究。Windows／Linux专业实机与作者定稿不从共享代码推定。
