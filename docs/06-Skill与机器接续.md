# Skill与机器接续

包内`hetu-poetry-studio`通过河图稳定plugins.inspect、capabilities和skills.read动态发现，不创建Codex插件或独立MCP服务。安装／升级／启用后重新发现，旧包绑定不能继续使用；工具可见不等于获权读取任何作品。

默认旅程：固定情境或原诗→准备诗篇与分节→明确需要的规则及读音→逐句比较→固定意见与返工→组诗阅读本和宿主候选。方法选择、阅读范围和判断依据由外部Agent负责，专业确定性规则由本包执行。先读现有成果和公开意见，不能为了演示创建另一份工程替代接续。

一行只能有一行文本，顺序在诗节内唯一；每个字的读音／平仄按位置显式记录，未知不猜。Profile固定名称、规则出处、每句模式与韵组，P／Z／*只按声明体系比较；字符计数不是音节。传统与现代方案不得混用。备选固定原句SHA，使用后清空旧音韵标注并保留旧意见；用典引文按UTF-8字节核对，不把借鉴标成引用。

保存保留CAS与原键，未知先get_operation，成功后回读固定修订。每阶段准备create_handoff的固定依据与下一步问题；其他专业插件按实际安装Schema独立发现，缺能力不能伪造交接成功。费用、外发、正文采纳、正式设定和定稿沿作者真实决定处理。

Skill入口保持精炼，专业方法归references/workflows，操作地图由正式清单生成。专业清单和Schema由本仓库维护，宿主地图只导航公共入口。
