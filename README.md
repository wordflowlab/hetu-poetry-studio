# 诗词工坊

> 河图洛书专业插件，保存诗篇、分节、用典、明确音韵与逐句取舍，让组诗可以沿固定版本继续创作。

## 简介

诗词的分行、留白、读音与典故本身就是创作结构。一次性生成难以保留某一字为何这样读、谱式来自哪里、为何破例以及旧意见针对哪一句。软件保存这些可复核结构，Agent理解语义与创作，作者决定诗意和取舍。

外部Agent经河图稳定CLI/MCP操作，作者阅读、比较与提意见。包内Skill随活动插件发现，专业成果、来源及修订可继续使用。

## 快速上手

Node.js 25、npm及河图0.12.6或更新版本。

```bash
npm ci
npm run build
npm run check
npm run test:unit
npm run package
```

正式宿主和运行包由acceptance-lock.json固定，安装后从河图稳定入口发现本包，不另安装Codex插件。

## 边界

不默认套近体诗或现代普通话，不内置未经许可的韵书字表，不声称完成传统整诗认证。自由诗无需选择格律。演唱和录音对齐归歌词工坊；书稿编译归交付插件。
