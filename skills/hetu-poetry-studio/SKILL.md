# 诗词工坊

从河图稳定CLI/MCP发现活动包、当前作品和实际Schema，先读已有工程、固定来源与意见，再执行目标。包内方法随插件发现，不另装Codex插件或MCP服务。

按[专业旅程](references/workflows.md)选择模式，[操作地图](references/operations.md)定位当前参数。一行只能有一行文本，顺序在诗节内唯一；每个字的读音／平仄按位置显式记录，未知不猜。Profile固定名称、规则出处、每句模式与韵组，P／Z／*只按声明体系比较；字符计数不是音节。传统与现代方案不得混用。备选固定原句SHA，使用后清空旧音韵标注并保留旧意见；用典引文按UTF-8字节核对，不把借鉴标成引用。

保存携带CAS与原键，未知先get_operation，成功后回读固定修订。专业工程与正文采纳分开，外发、费用、正式选用与定稿按本次作者决定执行。
